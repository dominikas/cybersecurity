## Cybersecurity portfolio

Hi! <br>
My name is Dominika. As a Senior Software Engineer with deep QA and automation expertise, I bring a validation-first mindset to cybersecurity—treating threat detection and control efficacy with the same rigor as test coverage. 
My transition into security is driven by a desire to apply my analytical skills where they matter most: protecting systems that underpin business continuity. 
I view security as a collaborative enabler, integrating secure practices into the SDLC through automation so that protection scales without slowing innovation. 
By combining engineering discipline with continuous learning in emerging threats, I help organizations achieve resilient, compliant, 
and developer-friendly security postures—turning security from a compliance checkbox into a measurable business advantage.
