### Security risk assessment report 

| Part 1: Select up to three hardening tools and methods to implement                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| After reviewing the organization’s network, I discovered major vulnerabilities, which are: <br> • The organization’s employees' share passwords. <br> • The admin password for the database is set to the default. <br> • The firewalls do not have rules in place to filter traffic coming in and out of the network. <br> • Multifactor authentication (MFA) is not used. <br> To address those vulnerabilities and prevent next data breaches, I would recommend: <br> 1. setting and enforcing password policies for employees, <br> 2. performing firewall maintenance, <br>  3. creating server and data storage backups.  |

| Part 2: Explain your recommendations                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1. Password policies for employees <br> Policies can be refined to include rules regarding password length, a list of acceptable characters, and frequency of changing it. <br>  Creation of a set of rules for the passwords that employees use is important, because it is harder for attacker to find the passwords using various types of attacks. The attack should be prevented, it maximum failed logging attempt policy is added. Employees should be educated about how those policies are important and that sharing password is very dangerous practice. | |
| 2. Firewall maintenance.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| It is about checking and updating security configuration regularly to stay ahead of potential threats. It is important, because it can enable network administrators to easily block traffic from a source that is trying DoS attack or any suspicious traffic.                                                                                                                                                                                                                                                                                                     |
| 3. Server and datastorage backups                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Creating a server and data storage backups is about having duplicate of data that is important for an organization, in a separate place than original one. <br> Backups can be recorded and stored in a physical location or uploaded/synced to a cloud repository.  To prevent big data loses because of a successful attack/human error etc., backups can be used to restore the data so the system can easily recover and function as before, with minimal effort. Creating backups can be automated process.|
