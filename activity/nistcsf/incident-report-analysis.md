### Incident report analysis

|          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|----------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Summary  | The organization recently experienced a DoS attack, which compromised the internal network for two hours until it was resolved. <br> During the attack, the organization’s network services suddenly stopped responding due to an incoming flood of ICMP packets. The incident management team responded by blocking incoming ICMP packets, stopping all non-critical network services offline, and restoring critical network services. <br> The targeted system was social media marketing tool that automatically publish posts for our customers. It causes that the service was not able to respond in time because a huge traffic coming to it. |
| Identify | The organization recently experienced a DoS attack. DoS is Denial Of Service attack. It is a type of attack that targets a network or server and floods it with network traffic. In our case it was ICMP flood. ICMP is Internet Control Message Protocol used by devices to tell each other about data transmission errors across the network. <br> When huge number of connections is being made to a server, its’ resources being drained, so eventually server cannot respond to next connections. In our case, it was social media marketing tool that was unreachable.                                                                          |
| Protect  | The security team implement firewall rules for incoming traffic to limit the rate of incoming ICMP packets and Intrusion Detect System /Intrusion Prevent System system to filter out some ICMP traffic based on suspicious characteristics.                                                                                                                                                                                                                                                                                                                                                                                                          |
| Detect   | To detect this kind of attack, the monitoring of network traffic was implemented. Anomalies in spike of traffic, suspicious IP addresses, flaw of certain packets are monitored and automatic alert are sent to the security team.                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Respond  | For future cases of this kind of attack, the immediate response will be taken when alerts are raised by a monitoring tool. Affected system should be isolated – no network traffic should be redirected to that system. Next, suspicious network traffic will be analyzed and blocked if needed. Those suspicious connections will be reported to higher management, if needed.                                                                                                                                                                                                                                                                       |
| Recover  | To recover after this kind of attack, access to the network needs to be restored for targeted systems. Flood attacks should be prevented on firewall level. Non critical services should be switched off to reduce the network traffic. After attack finished, critical services should be restored. Later rest of the non critical services.                                                                                                                                                                                                                                                                                                         |
