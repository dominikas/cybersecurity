### Security incident report

| Section 1: Identify the network protocol involved in the incident                                                                                                                                    |
|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Based on provided [tcpdump-traffic-log.docx](tcpdump-traffic-log.docx) file, the identified protocol is HTTP. The issue was with accessing the web server for  yummyrecipesforme.com and connecting to it involve http traffic. |

| Section 2: Document the incident                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Yesterday, multiple customers reached yummyrecipesforme’s helpdesk. They complained that the company’s website had prompted them to download a file to access free recipes. The customers claimed that, after running the file, the address of the website changed and their personal computers began running more slowly. <br> To verify those complaints, the security analyst used sandbox environment. The scenario about downloading a file and redirection to a different page was confirmed. <br> Next, tcpdump was used to capture network traffic during connection with  yummyrecipesforme website. Based on a analysis of traffic logs, it was proven that after downloading file from web server, the network traffic is changed to a different page: greatrecipesforme.com. <br> The senior cybersecurity analyst checked the source code of the corrupted website and found that it was changed – java script with downloading file was added. Deeper investigation proven that the malicious attacker, after several of attempts to login to admin panel, was able to add this code. The brute force attack on panel admin was overlooked. |
